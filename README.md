Amazon Campaign Prediction using Linear Regression
📌 Project Overview

This project uses Machine Learning to predict outcomes related to Amazon advertising campaigns using Linear Regression. The goal is to analyze campaign data and understand how different features influence the target variable.

🎯 Objectives
Analyze Amazon campaign data.
Perform data cleaning and preprocessing.
Explore relationships between input features and the target variable.
Build a Linear Regression model.
Evaluate model performance and interpret coefficients.
🛠️ Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Statsmodels
Jupyter Notebook
📊 Machine Learning Algorithm

Linear Regression

Linear Regression is used to model the relationship between input features and a continuous target variable.

⚙️ Project Workflow
Import required libraries.
Load and explore the dataset.
Handle missing values and preprocess data.
Split data into training and testing sets.
Scale features where required.
Train the Linear Regression model.
Evaluate model performance.
Interpret the intercept and coefficients.
Analyze residuals using the Durbin-Watson statistic.
📈 Model Evaluation

The model can be evaluated using:

R² Score
Mean Absolute Error (MAE)
Mean Squared Error (MSE)
Root Mean Squared Error (RMSE)
Durbin-Watson Statistic for residual autocorrelation analysis
